# Suivi du projet

Trello est la référence de suivi de Dune Legacy Tablet HD, conformément à la décision de l’utilisateur du 5 septembre 2026.

Tableau : https://trello.com/b/7mAO3AhC/dune-legacy-tablet-hd-modernisation-tablette

- Avant de commencer une étape, consulter le tableau et la carte concernée pour retrouver les priorités, décisions et critères de validation.
- Maintenir les cartes à jour pendant le travail : En cours, puis À tester sur tablette lorsqu’un APK est prêt, puis Terminé après les validations requises.
- Consigner dans la carte les résultats, limites connues, références de commits et artefacts utiles. Ne pas déclarer un test réel réussi sans preuve ou confirmation de l’utilisateur.
- Utiliser Trello pour le suivi ; conserver le code et la documentation technique dans le dépôt. Éviter une seconde liste de tâches divergente dans le dépôt.
- Les nouvelles instructions explicites de l’utilisateur priment ; répercuter les décisions de périmètre et de priorité dans Trello.
- Si Trello est inaccessible, le signaler et préciser les mises à jour restant à synchroniser sans inventer l’état des cartes.
